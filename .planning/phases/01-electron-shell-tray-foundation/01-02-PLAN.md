<task type="auto">
  <name>Task 1: Create popup window module with positioning and toggle</name>
  <files>
    src/main/window.ts
    src/main/tray.ts
    src/main/index.ts
  </files>
  <action>
    1. Create `src/main/window.ts` -- Popup window management:
       - Import `BrowserWindow, screen` from electron, `path` and `is` from `@electron-toolkit/utils` (or use `app.isPackaged`)
       - Module-level: `let popupWindow: BrowserWindow | null = null`
       - Export function `getPopupWindow(): BrowserWindow | null` -- returns current popup reference
       - Export function `createPopupWindow(trayBounds: Electron.Rectangle): BrowserWindow`:
         a. If popupWindow already exists and is not destroyed, return it
         b. Define window dimensions: width=380, height=480
         c. Calculate position:
            - x = Math.round(trayBounds.x + (trayBounds.width / 2) - (width / 2))
            - y = Math.round(trayBounds.y - height)
            - Clamp to screen bounds using `screen.getPrimaryDisplay().workAreaSize`
            - Ensure x >= 0, y >= 0, x + width <= screenWidth, y + height <= screenHeight
         d. Create BrowserWindow with:
            - width, height, x, y (calculated above)
            - show: false (prevents flash)
            - frame: false (frameless popup)
            - resizable: false
            - skipTaskbar: true (don't show in taskbar)
            - alwaysOnTop: true
            - webPreferences: { contextIsolation: true, nodeIntegration: false, preload: path.join(__dirname, '../preload/index.js') }
         e. Register `popupWindow.on('blur', () => { popupWindow?.hide(); })` -- hide on focus loss
         f. Register `popupWindow.on('closed', () => { popupWindow = null; })` -- clean up reference
         g. Register `popupWindow.once('ready-to-show', () => { popupWindow?.show(); })` -- show after render
         h. Load the renderer:
            - In dev: `popupWindow.loadURL(process.env['ELECTRON_RENDERER_URL'] || 'http://localhost:5173')`
            - In prod: `popupWindow.loadFile(path.join(__dirname, '../renderer/index.html'))`
            - Use `process.env.NODE_ENV === 'development'` or check `ELECTRON_RENDERER_URL` existence to determine mode
         i. Return popupWindow

       - Export function `togglePopupWindow(trayBounds: Electron.Rectangle): void`:
         a. If popupWindow and popupWindow.isVisible(), call popupWindow.hide() and return
         b. If popupWindow and not destroyed, reposition (update x/y using same calculation), then show and focus
         c. If no popupWindow, call createPopupWindow(trayBounds)

    2. Modify `src/main/tray.ts`:
       - Import `togglePopupWindow` from `./window`
       - In `createTray()`, after setting context menu, add:
         ```typescript
         tray.on('click', () => {
           if (tray) {
             togglePopupWindow(tray.getBounds());
           }
         });
         ```
       - Keep all existing code (context menu, tooltip, icon management) unchanged

    3. Modify `src/main/index.ts`:
       - Import `getPopupWindow` from `./window`
       - Import `tray` from `./tray` (the module-level tray reference)
       - Update `second-instance` handler to:
         ```typescript
         app.on('second-instance', () => {
           const popup = getPopupWindow();
           if (popup) {
             if (popup.isMinimized()) popup.restore();
             popup.show();
             popup.focus();
           } else if (tray) {
             togglePopupWindow(tray.getBounds());
           }
         });
         ```
       - Import `togglePopupWindow` from `./window` for the second-instance handler

    IMPORTANT:
    - Do NOT set nodeIntegration: true
    - The blur handler is what makes the popup auto-hide when clicking away -- this is critical UX
    - Use ready-to-show to prevent white flash
    - The window must be skipTaskbar:true so it doesn't appear in the Windows taskbar
  </action>

    - `npm run dev` launches app; clicking tray icon shows popup near system tray area
    - Clicking tray icon again hides the popup (toggle)
    - Clicking outside the popup hides it (blur handler)
    - Popup has no window frame (frameless)
    - Popup does not appear in the Windows taskbar
  </verify>
