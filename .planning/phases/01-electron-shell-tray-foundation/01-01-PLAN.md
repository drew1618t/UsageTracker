<task type="auto">
  <name>Task 2: Implement main process with single instance, tray icon, and context menu</name>
  <files>
    src/main/index.ts
    src/main/tray.ts
    src/preload/index.ts
    src/preload/index.d.ts

  <action>
    1. Create `src/main/tray.ts` -- Tray management module:
       - Export `let tray: Tray | null = null` at module scope (prevents GC)
       - Export function `createTray(): Tray` that:
         a. Resolves icon path: in dev use `path.join(__dirname, '../../resources/icons/tray-green.ico')`, in production use `path.join(process.resourcesPath, 'icons/tray-green.ico')`
         b. Creates `nativeImage.createFromPath(iconPath)`
         c. Creates `new Tray(icon, '7c3e8f2a-4b6d-9e1f-a5c0-d8b7f6324198')` -- GUID for persistent positioning
         d. Sets tooltip: `tray.setToolTip('Claude Usage Widget')`
         e. Builds and sets context menu with Menu.buildFromTemplate:
            - `{ label: 'Refresh', click: () => { /* placeholder */ } }`
            - `{ label: 'Settings', click: () => { /* placeholder */ } }`
            - `{ label: 'Login', click: () => { /* placeholder */ } }`
            - `{ type: 'separator' }`
            - `{ label: 'Exit', click: () => { app.quit(); } }`
         f. Returns the tray instance
       - Export function `updateTrayIcon(status: 'green' | 'yellow' | 'red'): void` that:
         a. Guards: if (!tray) return
         b. Resolves icon path for given status (same dev/prod logic)
         c. Calls `tray.setImage(nativeImage.createFromPath(iconPath))`

    2. Create `src/main/index.ts` -- App entry point:
       - Import `app, BrowserWindow` from electron
       - Import `createTray` from `./tray`
       - Call `const gotTheLock = app.requestSingleInstanceLock()`
       - If `!gotTheLock`, call `app.quit()` and return early (do NOT proceed to whenReady)
       - Register `app.on('second-instance', ...)` handler that will later focus the popup window (for now, just log "Second instance attempted")
       - Register `app.on('window-all-closed', (e) => { e.preventDefault(); })` to keep tray alive
       - In `app.whenReady().then(...)`:
         a. Call `createTray()`
         b. Log "Tray created successfully" to console
       - Register `app.on('before-quit', ...)` to clean up tray if needed

    3. Create `src/preload/index.ts` -- Secure IPC bridge:
       - Import `contextBridge, ipcRenderer` from electron
       - Use `contextBridge.exposeInMainWorld('electronAPI', { ... })` exposing:
         a. `getVersion: () => ipcRenderer.invoke('app:get-version')`
         b. `refreshData: () => ipcRenderer.invoke('app:refresh-data')`
         c. `onTrayAction: (callback: (action: string) => void) => { ipcRenderer.on('tray:action', (_e, action) => callback(action)); }`
         d. `removeAllListeners: (channel: string) => { ipcRenderer.removeAllListeners(channel); }`

    4. Create `src/preload/index.d.ts` -- Type declarations for the exposed API:
       ```typescript
       export interface ElectronAPI {
         getVersion: () => Promise<string>;
         refreshData: () => Promise<void>;
         onTrayAction: (callback: (action: string) => void) => void;
         removeAllListeners: (channel: string) => void;
       }

       declare global {
         interface Window {
           electronAPI: ElectronAPI;
         }
       }
       ```

    IMPORTANT: Do NOT use `nodeIntegration: true` anywhere. Keep `contextIsolation: true` (the default). Never expose raw ipcRenderer to the renderer.
  </action>
