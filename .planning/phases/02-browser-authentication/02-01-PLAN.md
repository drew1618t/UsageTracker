  <action>
Create the auth module following patterns from 02-RESEARCH.md:

**src/main/auth/session.ts:**
- Use `session.fromPartition('persist:main')` for persistent cookie storage
- `initSession()`: Set up cookie change listener with `cookies.on('changed')`, detect Claude.ai auth cookies (check for cookies on `.claude.ai` domain - look for `__cf_bm`, `__client`, or `sessionKey` patterns), call `onAuthSuccess` callback when detected
- `checkAuthState()`: Query existing cookies with `ses.cookies.get({ domain: '.claude.ai' })`, return { isAuthenticated: boolean, userEmail?: string } - try to extract email from cookies if available, otherwise just return isAuthenticated
- `persistSessionCookies()`: Convert session cookies (those without expirationDate) to persistent by re-setting with 30-day expiration. Use correct URL protocol based on cookie.secure flag: `${cookie.secure ? 'https' : 'http'}://${cookie.domain.replace(/^\./, '')}${cookie.path}`
- `logout()`: Clear all Claude.ai cookies with `ses.cookies.remove()`

**src/main/auth/browser.ts:**
- `openLoginPage()`: Validate URL is Claude.ai HTTPS, then call `shell.openExternal('https://claude.ai/login')`
- Keep it simple - just opens browser, detection is handled by session.ts

**src/main/auth/state.ts:**
- Interface `AuthState { isAuthenticated: boolean; userIdentifier: string | null }`
- Module-level state: `let authState: AuthState = { isAuthenticated: false, userIdentifier: null }`
- `getAuthState()`: Return current state
- `setAuthState(state)`: Update state, emit 'auth-state-changed' to all BrowserWindows via webContents.send, call `updateTrayForAuthState(state.isAuthenticated)` (import from tray.ts - will be added in Task 2)
- Export type for use in preload

**src/main/auth/index.ts:**
- Barrel export all from session, browser, state

- In `app.whenReady()`:
  - Call `initSession()` with callback that:
    1. Calls `persistSessionCookies()` to make session cookies persistent
    2. Calls `checkAuthState()` to get auth info
    3. Calls `setAuthState()` with the result
  - After tray creation, call `checkAuthState()` and `setAuthState()` for initial state
- Register IPC handlers:
  - `ipcMain.handle('auth:get-state', () => getAuthState())`
  - `ipcMain.handle('auth:login', async () => { openLoginPage() })`
  - `ipcMain.handle('auth:logout', async () => { await logout(); setAuthState({ isAuthenticated: false, userIdentifier: null }) })`

**Update src/preload/index.ts:**
- Add to electronAPI:

  - `onAuthStateChanged: (callback) => { ipcRenderer.on('auth-state-changed', (_e, state) => callback(state)); return () => ipcRenderer.removeListener('auth-state-changed', callback) }`

**Update src/preload/index.d.ts:**
