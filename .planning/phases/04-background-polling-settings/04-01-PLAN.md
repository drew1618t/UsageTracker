    Create src/main/state/polling.ts following the research patterns:

    1. Import backOff from 'exponential-backoff'
    2. Import refreshUsageData from './usage'
    3. Import getSettings from './settings'

    4. State variables:
       - let pollingTimer: NodeJS.Timeout | null = null
       - let isPolling = false

    5. fetchWithRetry() async function:
       - Uses backOff() wrapper around refreshUsageData()
       - Config: numOfAttempts: 5, startingDelay: 1000, timeMultiple: 2, maxDelay: 60000, jitter: 'full'
       - Custom retry callback: return false for auth errors (contains 'Not authenticated' or '401' or '403')
       - Log retry attempts for debugging

    6. poll() async function (recursive setTimeout pattern):
       - If !isPolling, return early (allows stopping)
       - try/catch fetchWithRetry(), log errors
       - After completion (success or error), schedule next poll:
         ```typescript
         const settings = getSettings()
         const intervalMs = settings.pollingIntervalMinutes * 60 * 1000
         pollingTimer = setTimeout(poll, intervalMs)
         ```

    7. startPolling() function:
       - If already polling, log and return
       - Set isPolling = true
       - Call poll() to start immediately
       - Log '[Polling] Started'

    8. stopPolling() function:
       - If !isPolling, return
       - Set isPolling = false
       - clearTimeout(pollingTimer), set to null
       - Log '[Polling] Stopped'

    9. restartPolling() function:
       - Calls stopPolling() then startPolling()

    Export: startPolling, stopPolling, restartPolling
  </action>
