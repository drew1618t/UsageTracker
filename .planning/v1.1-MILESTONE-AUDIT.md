### Integration Gap Details

**Auth Expiry Handling** (Non-critical)

When a session expires during app operation:
1. ✓ Polling detects 401/403 error
2. ✓ Polling stops retry loop for that cycle
3. ✗ Auth state NOT updated to `isAuthenticated: false`
4. ✗ Tray icon stays green/yellow/red instead of gray
5. ✗ Context menu still shows "Logout" instead of "Login"

**Location:** `src/main/state/polling.ts:44-48`

**Impact:** User sees stale "logged in" state until they manually interact with app. Polling continues next cycle and fails again. Not a blocker because user can still manually trigger re-login.

**Fix (if desired):**
```typescript
// In polling.ts catch block for auth errors:
if (errorMsg.includes('Not authenticated') ||
    errorMsg.includes('401') || errorMsg.includes('403')) {
  const { setAuthState } = await import('../auth/state')
  setAuthState({ isAuthenticated: false, userIdentifier: null })
  stopPolling()
  return
}
```
